# 25 工单实机演练：离线阅读资料库

## 目标与边界

在隔离的本机项目中，使用 Lachesis 把 25 张工单从领取、真实模型施工、权限答复、冻结交付、人工验收、评分、集成到显式应用跑完。最终交付是无需账号或云服务、可离线使用的阅读资料库：保存书籍、文章和链接，整理阅读进度与笔记，支持查找和备份。数据只留在浏览器；不接触用户现有资料，不发布到外网。

施工 Profile 固定为 `minimax-m3`、`step-5-preview`、`mimo-v2.6-flash`，均走本机 OCG 的 `local-ocg`，使用供应商默认推理强度。每张工单必须有冻结交付及独立验收，不能把模型报告当作验收证据。单批次应用成功后才释放下一批依赖。

项目目录：`.lachesis/reading-ledger-real-run/target`；Lachesis 数据目录：`.lachesis/reading-ledger-real-run/data`。这是隔离验收项目，不是 Lachesis 产品源码。项目使用原生 HTML/CSS/JavaScript 和 Node 内置测试工具，避免网络依赖。每批通过 `node --test`，最终另做浏览器实测。所有外部发布仍需单独授权。
